# RexCruxCorp/.github

This repository holds the default community health files for the RexCruxCorp organization.

Any repository in this org that doesn't define its own copy of these files automatically inherits the ones here:

- Issue templates (`.github/ISSUE_TEMPLATE/`)
- Pull request template (`.github/PULL_REQUEST_TEMPLATE.md`)
- [CONTRIBUTING.md](./CONTRIBUTING.md)
- [CODE_OF_CONDUCT.md](./CODE_OF_CONDUCT.md)
- [SECURITY.md](./SECURITY.md)

To override any of these for a specific repo, add the same file at the same relative path in that repo — the local copy takes precedence over this default.
