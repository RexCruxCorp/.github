# Security Policy

## Reporting a Vulnerability

If you believe you've found a security vulnerability in a RexCrux repository, please report it privately rather than opening a public issue.

Email **info@rexcrux.com** with:

- A description of the vulnerability and its potential impact
- Steps to reproduce, including proof-of-concept code if available
- Any relevant logs, configuration, or environment details

We aim to acknowledge reports within 3 business days and will work with you on a disclosure timeline once the issue is confirmed. Please do not publicly disclose the issue until we've had a chance to address it.

## Supported Versions

RexCrux repositories are under active development. Security fixes are applied to the latest version on `main`; there is currently no formal long-term-support branch.

## Scope

This policy covers the RexCruxCorp organization's repositories, including FoldShield++, OmegaSignal, QPhase, and the UL DSL/USL toolchain.
